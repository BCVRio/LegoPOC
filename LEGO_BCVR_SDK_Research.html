Body Motion Capture — SDKs & Plugins

How to get suit data from Rokoko or Xsens into Unreal Engine in real time

🔴
Rokoko Studio Live Plugin
Epic Fab Marketplace · Free
The official Rokoko UE plugin streams Smartsuit Pro body data and face capture directly into Unreal via Live Link. Supports UE 5.4–5.7. Provides a Rokoko Studio Source in the Live Link panel. Available on Epic's Fab marketplace or directly via GitHub.
Rokoko Studio Live Live Link Free on Fab
unrealengine.com → Rokoko Studio Live plugin github.com/Rokoko/rokoko-studio-live-unreal-engine
📡
Xsens MVN Live Link Plugin
Epic Fab Marketplace · Free with Xsens licence
Xsens (now Movella) official plugin receives real-time streams from MVN Animate or MVN Analyze software. Supports full body, fingers, props, VIVE objects. Supports UE 5.4, 5.5, 5.6, and 5.7. Blueprint remote control of MVN included. Timecode sync supported.
MVN Live Link Live Link Free with suit
xsens.com/integrations/unreal-engine fab.com → Xsens Live Link listing

Both systems use Unreal's native Live Link framework as the bridge. Here's how to set up either one:

UNREAL ENGINE SETUP — Enable Required Plugins (Edit → Plugins)
// Required plugins to enable in your UE project:

Live Link                        // Core Live Link framework — built into UE
Live Link Hub                    // Multi-source recording & sync (UE 5.4+)
Rokoko Studio Live  OR  MVN Live Link   // Your mocap suit plugin
Apple ARKit                      // Required for face capture (even on PC)
Apple ARKit Face Support         // Enables ARKit blendshape parsing
Live Link Control Rig            // Allows Control Rig + Live Link combination
UDP Messaging                    // CRITICAL — must enable before packaging for broadcast
Install the plugin via Epic Fab / GitHub
For Rokoko: search "Rokoko Studio Live" in Fab and click Install Plugin, selecting your UE version. For Xsens: search "Xsens Live Link" on Fab. Alternatively clone the GitHub repo and place the Plugins/ folder in your UE project root.
Launch Rokoko Studio (or MVN Animate) and enable streaming
In Rokoko Studio: Settings → Plugin → Unreal Engine → enter your UE machine's IP (127.0.0.1 if same machine). Set port (default 14043). Enable "Forward to Unreal". In MVN: use the network streamer to output on the same port Unreal expects.
Open Live Link window in Unreal and Add Source
Window → Virtual Production → Live Link. Click "Add Source". For Rokoko, the Rokoko Studio Source should auto-appear. For Xsens, choose "Add → Xsens Live Source" and enter the port. You'll see the performer skeleton appear as a subject.
Configure rotation order (Rokoko-specific)
In the Live Link panel, click on the Studio subject. Set "Use Rotation Order ZYX" and add 90° Hip Pre-rotation. Skip this and characters will be rotated incorrectly on play.
Create Animation Blueprint and add Live Link Pose node
Right-click your character's Skeletal Mesh → Create Animation Blueprint. Inside the AnimGraph, right-click → Add "Live Link Pose" node. Set the subject name to match what appears in the Live Link panel. Wire it to Output Pose. Hit Play — your character should move with the performer.
⚠️
iOS 26 compatibility issue: Recent App Store reviews (May 2026) note that the Live Link Face app crashes after 10–15 minutes on iOS 26. If using iPhones for face capture, stay on iOS 18 until Epic release a fix, or use a dedicated Android device for the POC.

Face Capture — ARKit & Live Link Face

Real-time facial performance into Unreal Engine via iPhone or Android

😶
Live Link Face App (Epic Games)
iOS / Android · Free
Free app from Epic. Uses the iPhone TrueDepth / Face ID camera and Apple ARKit to capture 52 facial blend shape coefficients — streaming them over Wi-Fi to Unreal Engine in real time. Supports timecode sync via Tentacle Sync. In UE 5.7, also supports external USB-C cameras on iPads and Android devices.
Free App ARKit 52 blendshapes Timecode support
App Store → Live Link Face
🎭
Apple ARKit (UE Plugin)
Built into Unreal Engine · Free
Built into UE5. Parses the 52 ARKit blend shape values coming from the Live Link Face app and applies them to any ARKit-compatible character rig. LEGO characters will need ARKit blendshapes authored on their face mesh for this to work — this is a key build task.
Built into UE No cost
Epic Docs → Face Animation on iOS
💡
Key LEGO-specific task: MetaHumans have 52 ARKit blendshapes pre-built by Epic, so face capture works out of the box. Your LEGO characters will need ARKit blendshapes manually authored on the face mesh — this is an art task, not a technical one, but it's a build step that needs to be scoped into Week 3–4 of the timeline.
FACE CAPTURE SETUP — Step by Step
// iPhone setup
1. Install Live Link Face app (App Store, free)
2. Connect iPhone to same Wi-Fi network as Unreal Engine machine
3. In app: Settings → set UE machine IP address, port 11111 (default)
4. Start streaming in app

// Unreal Engine setup
5. Enable plugins: Apple ARKit + Apple ARKit Face Support + Live Link
6. Window → Virtual Production → Live Link
7. "Add Source" → iPhone should appear automatically as a subject
8. Subject name typically shown as "iPhone" (or device name)

// Applying to LEGO character
9. In your character's AnimBP, add Live Link Pose node for face subject
10. Map ARKit curve names to LEGO face blendshapes via curve remapping
11. Use "Live Link Remap Asset" to translate standard ARKit names
     to your LEGO character's custom morph target names

// Body + Face sync (running simultaneously)
12. In AnimBP: two Live Link Pose nodes — one for body (suit), one for face (iPhone)
13. Use Live Link Hub (UE 5.4+) to record and sync both streams with timecode

LEGO Character Retargeting — IK Rig System

Translating human mocap proportions to LEGO minifigure skeleton in real time

This is the most custom-build-intensive part of the pipeline. UE5's IK Rig + IK Retargeter system is the primary tool. UE 5.7 added Spatially Aware Retargeting — which specifically helps with characters of very different proportions (e.g. giant-to-dwarf) — directly applicable to human→LEGO retargeting.

🦴
IK Rig & IK Retargeter
Built into UE5 · Free
UE5's native retargeting system. Define bone chains on both the source (human mocap skeleton) and target (LEGO skeleton). The Retargeter maps motion between them, handling proportion differences, joint constraints, and foot/hand contact. Build once, applies to all animations from that source.
IK Rig IK Retargeter Built into UE5
Epic Docs → IK Rig Retargeting
⚙️
Control Rig
Built into UE5 · Free
Used on top of the retargeter to add the LEGO stylization layer — the squash/stretch, timing exaggeration, and joint constraint clamping that makes the movement feel authentically LEGO rather than just "a tiny human". Essential for the POC quality target.
Control Rig Built into UE5
Epic Docs → Control Rig
RETARGETING WORKFLOW — Human Mocap → LEGO Skeleton
// PHASE 1: Build the LEGO IK Rig (do once)
1. Import LEGO character FBX with custom skeleton into UE
2. Right-click LEGO Skeleton → Create IK Rig
3. In IK Rig editor, define bone chains:
     Spine chain:    Pelvis → Spine_01 → Spine_02 → Neck → Head
     Left arm:       Clavicle_L → UpperArm_L → LowerArm_L → Hand_L
     Right arm:      (mirror of above)
     Left leg:       Thigh_L → Calf_L → Foot_L
     Right leg:      (mirror of above)
4. Set LEGO-specific joint limits (e.g. no wrist rotation, limited elbow bend)
5. Add Full Body IK goal for foot grounding

// PHASE 2: Build IK Rig for the mocap source skeleton (Rokoko/Xsens)
6. Create IK Rig for the source skeleton coming from the suit
7. Define the same chain structure (UE preset naming convention works well)

// PHASE 3: Create the IK Retargeter
8. Right-click in Content Browser → Create IK Retargeter
9. Assign Source IK Rig (human) and Target IK Rig (LEGO)
10. Use alignment tools to match root positions
11. Enable Spatially Aware Retargeting (UE 5.7) for proportion difference handling
12. Adjust Target Actor Scale if needed; test in Preview window

// PHASE 4: Live retargeting via Animation Blueprint
13. In LEGO character AnimBP: receive Live Link body data
14. Pass through Retarget Component referencing the IK Retargeter
15. Layer Control Rig on top for stylization (squash, timing, constraints)
16. Output Pose → character moves in real time
✅
UE 5.7 advantage: The new Spatially Aware Retargeting feature in 5.7 is specifically designed to reduce self-collision and artifacts when retargeting between characters of very different scale and proportions. This is directly relevant to human→LEGO retargeting and should be the target engine version for this pipeline.

Broadcast Output — NDI, Alpha Feeds & Live Switching

Getting Unreal's output onto air and into downstream broadcast systems

📺
NDI Unreal Engine SDK
NDI (Vizrt) · Free SDK
Adds full IP video/audio support within Unreal Engine 5.6+. Enables UE to send and receive video streams over IP — including alpha channel — up to 4K. You can add NDI Broadcast Actors to the level (one per camera) and stream each to separate NDI channels simultaneously. Downstream tools like vMix, OBS, or dedicated broadcast switchers receive these feeds.
Free SDK NDI Protocol UE 5.6+
ndi.video/for-developers/ndi-unreal-engine-sdk
🎬
Unreal Motion Design / Broadcast Mode
Built into UE5 · Free
UE5's Motion Design tools (formerly Motion Design plugin) enable broadcast-style graphics, lower thirds, stingers, and overlays built directly inside Unreal — no external graphics system needed for the POC. Operators can trigger and control these via OSC or Blueprint from a production desk.
Motion Design Built into UE5
Epic Docs → Motion Design
🔀
vMix / OBS (Production Switcher)
3rd Party · vMix from $60 one-time
Receives NDI streams from Unreal (LEGO characters, sports footage, graphics). Acts as the production switcher for the POC — handling camera cuts, transitions, scene presets, and final programme output. vMix is the industry standard for this. OBS is free but less robust under live pressure.
NDI compatible vMix licence
vmix.com
NDI OUTPUT SETUP — Unreal Engine to vMix/Switcher
// Install NDI SDK
1. Download NDI Unreal Engine SDK from ndi.video/for-developers
2. Place plugin in your UE project's Plugins/ folder
3. Enable "NDI IO Plugin" in UE Plugins panel — restart UE

// Set up multiple NDI output streams (one per virtual camera)
4. In Level, open Place Actors → search "NDI Broadcast Actor"
5. Drop one per camera angle (Wide, Medium, Close-up)
6. For each actor, create an NDI Media Sender asset:
     Stream name: "UE_Wide", "UE_Medium", "UE_CloseUp"
     Resolution: 1920x1080 @ 50/60fps
7. For alpha/keyed output: add an alpha channel pass to the render target
8. Enable "Begin Broadcast On Play" in Project Settings → NDI

// In vMix (or any NDI-compatible switcher)
9.  Add Input → NDI → search for "UE_Wide" etc. on the network
10. Add second input for live sports footage (from sports feed or file)
11. Composite LEGO characters over sports using vMix Chroma Key or Alpha channel
12. Set up scene presets: Wide 2-shot, Medium single, Close-up, Replay
13. Output to streaming encoder, record, and social clip simultaneously
✅
Multi-channel NDI in UE 5.7: A recent Epic tutorial (Nov 2025) demonstrates broadcasting multiple NDI channels live from UE 5.7 simultaneously — perfect for POC multi-camera output without any external hardware capture cards.

AR Layer — Real-Time Compositing & Broadcast AR

Overlaying LEGO characters and graphics onto live sports footage

There are two approaches for AR compositing. For the POC, Approach A (Composure in UE) is the fastest and cheapest path. Approach B (Zero Density Reality) is the broadcast-grade production path for full deployment.

🎭
Composure (Built into UE5)
Approach A — POC path · Free
Unreal's built-in real-time compositing framework. Can receive live video input (via NDI or capture card), composite the LEGO characters and CG elements over it, and output a final mixed frame — all inside UE without external software. Sufficient for the 2-minute POC.
Composure Plugin Built into UE5 POC path
Epic Docs → Composure Overview
📡
Zero Density Reality 5 (+ Lino)
Approach B — Full broadcast · Licensed
The industry standard for broadcast AR/XR production (used on FIFA World Cup, Super Bowl, Olympics). UE5-native platform with professional keying, node-based compositing, camera tracking, and real-time data integration. Reality 5.6 added Lino — a unified template-based workflow for 2D/3D overlays, AR, and virtual set graphics from a single control interface. Used by Fox Sports, RTL, The Weather Channel.
Licensed product UE5 native Broadcast grade
zerodensity.io → Reality platform
📷
Ncam AR Suite (UE Plugin)
Approach B alt · Licensed
An automated UE5 AR pipeline bridge. Connects real-time camera tracking data directly to Unreal Engine for film, TV and broadcast AR. Updated for UE5 with SDKLite protocol, wireless operation, and Epic's built-in lens distortion framework. Used on Amazon and Warner Bros productions.
Licensed UE5 plugin Camera tracking
ncam-tech.com
POC AR SETUP — Composure Approach (Inside UE5)
// Enable Composure Plugin
1. Edit → Plugins → search "Composure" → Enable → Restart UE

// Bring in live sports footage as video input
2. Option A — Use NDI to receive sports footage feed into UE:
     Add NDI Receive Actor → point to sports footage NDI source
3. Option B — Use Media Framework with video file (for POC testing):
     Create Media Source (file) → Media Player → Media Texture

// Build the compositing tree
4. Window → Composure
5. Create Comp Shot → add layers:
     Layer 1: Background plate (sports footage video input)
     Layer 2: CG characters (LEGO announcers from UE scene)
     Layer 3: Graphics overlays (score bugs, lower thirds)
6. For each CG layer: set up alpha keying / matte output
7. Apply colour matching between CG and video plate if needed

// Real-time depth / occlusion (advanced — Phase 3+)
8. For objects appearing IN FRONT OF real-world elements:
     Use depth pass + holdout mattes from Composure
     Or use Zero Density's proprietary depth compositor (Phase 3+)

// Output the composite
9. Route Composure output to NDI Broadcast Actor
10. This single "final composite" stream goes to vMix programme output
💡
Zero Density at NAB 2025: ZD demonstrated Reality 5.6 turning a compact LED stage into a full-scale virtual sports studio, with AR graphics controlled through a web-based interface using commands like "take in" and "take next". This is what Phase 3+ of the roadmap looks like — worth an evaluation conversation with ZD early.

Key Watch-outs & Technical Flags

Issues identified through research that need active management

🔴
iOS 26 / Live Link Face crash: Multiple App Store reviews (May 2026) confirm the Live Link Face app crashes after 10–15 minutes on iOS 26. Don't upgrade performer iPhones — stay on iOS 18 — or switch to Android devices for face capture until Epic release a patch. Flag this to the talent team now.
⚠️
LEGO face blendshapes are a custom art task: Unlike MetaHumans (which have 52 ARKit blendshapes pre-built), LEGO characters need ARKit morph targets authored from scratch. This is an art/rigging task that needs to be scoped into Week 3–4. Roughly 5–10 days for an experienced facial rigger.
⚠️
UDP Messaging plugin must be enabled before packaging: If you package the UE project for a broadcast build (e.g. running on a dedicated render machine), the UDP Messaging plugin must be enabled, and the network binding set to your specific IP — not 0.0.0.0 on Windows (which only binds to default interface). This is a common gotcha for live deployments.
💡
Rokoko vs Xsens — choose one for POC, plan for hybrid: Rokoko is cheaper and faster to set up; Xsens is more precise and field-proven at major broadcast events. For the POC, Rokoko is the pragmatic choice. For Phase 5 live events, Xsens or a hybrid workflow is worth evaluating. Both use the same Live Link architecture so swapping is possible.
💡
UE 5.7 is the target engine version: Spatially Aware Retargeting (specifically designed for extreme proportion differences), improved IK Retargeter, multi-NDI broadcast tutorials, and updated Live Link Face support (including Android and USB-C cameras) all landed in 5.7. Build on 5.7 from day one.
✅
Use Live Link Hub for multi-performer sync: With two performers (two suits + two iPhones), Live Link Hub (built into UE 5.4+) handles synchronising and recording all four streams simultaneously with timecode alignment. Set this up early — syncing two performers manually in AnimBP is error-prone under live conditions.
✅
Zero Density outreach — early Phase 3 conversation: ZD's Reality platform is UE5-native and was demonstrated at NAB 2025 turning a compact LED stage into a full virtual sports studio with web-controlled AR. An early conversation with ZD about the LEGO project — even just a demo — is worthwhile for Phase 3 scoping. They have an Open Studio License Program announced at IBC 2024.
