Body Motion Capture — SDKs & Plugins

How to get suit data from Rokoko or Xsens into Unreal Engine in real time

🔴
Rokoko Studio Live Plugin
Epic Fab Marketplace · Free
The official Rokoko UE plugin streams Smartsuit Pro body data and face capture directly into Unreal via Live Link. Supports UE 5.4–5.7. Provides a Rokoko Studio Source in the Live Link panel. Available on Epic's Fab marketplace or directly via GitHub.
Rokoko Studio LiveLive LinkFree on Fab
unrealengine.com → Rokoko Studio Live plugin github.com/Rokoko/rokoko-studio-live-unreal-engine
📡
Xsens MVN Live Link Plugin
Epic Fab Marketplace · Free with Xsens licence
Official Xsens plugin receives real-time streams from MVN Animate or MVN Analyze. Supports full body, fingers, props, VIVE objects. Supports UE 5.4–5.7. Blueprint remote control of MVN included. Timecode sync supported.
MVN Live LinkLive LinkFree with suit
xsens.com/integrations/unreal-engine fab.com → Xsens Live Link listing
UNREAL ENGINE SETUP — Enable Required Plugins
// Required plugins to enable in your UE project (Edit → Plugins):
Live Link                        // Core Live Link framework — built into UE
Live Link Hub                    // Multi-source recording & sync (UE 5.4+)
Rokoko Studio Live  OR  MVN Live Link   // Your mocap suit plugin
Apple ARKit                      // Required for face capture
Apple ARKit Face Support         // Enables ARKit blendshape parsing
Live Link Control Rig            // Control Rig + Live Link combination
UDP Messaging                    // CRITICAL — must enable before packaging
Install the plugin via Epic Fab / GitHub
For Rokoko: search "Rokoko Studio Live" in Fab and click Install Plugin, selecting your UE version. For Xsens: search "Xsens Live Link" on Fab. Alternatively clone the GitHub repo and place the Plugins/ folder in your UE project root.
Launch Rokoko Studio (or MVN Animate) and enable streaming
In Rokoko Studio: Settings → Plugin → Unreal Engine → enter your UE machine's IP (127.0.0.1 if same machine). Set port (default 14043). Enable "Forward to Unreal". In MVN: use the network streamer to output on the same port Unreal expects.
Open Live Link window in Unreal and Add Source
Window → Virtual Production → Live Link. Click "Add Source". For Rokoko, the Rokoko Studio Source should auto-appear. For Xsens, choose "Add → Xsens Live Source" and enter the port. You'll see the performer skeleton appear as a subject.
Configure rotation order (Rokoko-specific)
In the Live Link panel, click on the Studio subject. Set "Use Rotation Order ZYX" and add 90° Hip Pre-rotation. Skip this and characters will be rotated incorrectly on play.
Create Animation Blueprint and add Live Link Pose node
Right-click your character's Skeletal Mesh → Create Animation Blueprint. Inside the AnimGraph, right-click → Add "Live Link Pose" node. Set the subject name to match what appears in the Live Link panel. Wire it to Output Pose. Hit Play — your character should move with the performer.
⚠️
iOS 26 compatibility issue: Recent App Store reviews (May 2026) note that the Live Link Face app crashes after 10–15 minutes on iOS 26. Stay on iOS 18 until Epic release a fix, or use a dedicated Android device for the POC.

Face Capture — ARKit & Live Link Face

Real-time facial performance into Unreal Engine via iPhone or Android

😶
Live Link Face App (Epic Games)
iOS / Android · Free
Free app from Epic. Uses the iPhone TrueDepth / Face ID camera and Apple ARKit to capture 52 facial blend shape coefficients — streaming them over Wi-Fi to Unreal Engine in real time. Supports timecode sync via Tentacle Sync. In UE 5.7, also supports external USB-C cameras on iPads and Android devices.
Free AppARKit 52 blendshapesTimecode support
App Store → Live Link Face
🎭
Apple ARKit (UE Plugin)
Built into Unreal Engine · Free
Built into UE5. Parses the 52 ARKit blend shape values coming from the Live Link Face app and applies them to any ARKit-compatible character rig. LEGO characters will need ARKit blendshapes authored on their face mesh for this to work — a key build task in Week 3–4.
Built into UENo cost
Epic Docs → Face Animation on iOS
💡
Key LEGO-specific task: MetaHumans have 52 ARKit blendshapes pre-built by Epic, so face capture works out of the box. Your LEGO characters will need ARKit blendshapes manually authored on the face mesh — an art task scoped into Week 3–4.
FACE CAPTURE SETUP — Step by Step
// iPhone setup
1. Install Live Link Face app (App Store, free)
2. Connect iPhone to same Wi-Fi as Unreal Engine machine
3. In app: Settings → set UE machine IP address, port 11111 (default)
4. Start streaming in app

// Unreal Engine setup
5. Enable plugins: Apple ARKit + Apple ARKit Face Support + Live Link
6. Window → Virtual Production → Live Link
7. "Add Source" → iPhone appears automatically as subject
8. Subject name typically shown as "iPhone" (or device name)

// Applying to LEGO character
9.  Add Live Link Pose node in AnimBP for face subject
10. Map ARKit curve names to LEGO face blendshapes
11. Use Live Link Remap Asset to translate ARKit names to LEGO morph targets

// Body + Face sync (running simultaneously)
12. Two Live Link Pose nodes in AnimBP — one body (suit), one face (iPhone)
13. Use Live Link Hub (UE 5.4+) to record and sync both streams with timecode

LEGO Character Retargeting — IK Rig System

Translating human mocap proportions to LEGO minifigure skeleton in real time

UE5's IK Rig + IK Retargeter system is the primary tool. UE 5.7 added Spatially Aware Retargeting specifically for characters with very different proportions — directly applicable to human→LEGO retargeting.

🦴
IK Rig & IK Retargeter
Built into UE5 · Free
UE5's native retargeting system. Define bone chains on both the source (human mocap skeleton) and target (LEGO skeleton). The Retargeter maps motion between them, handling proportion differences, joint constraints, and foot/hand contact. Build once, applies to all animations from that source.
IK RigIK RetargeterBuilt into UE5
Epic Docs → IK Rig Retargeting
⚙️
Control Rig
Built into UE5 · Free
Used on top of the retargeter to add the LEGO stylization layer — the squash/stretch, timing exaggeration, and joint constraint clamping that makes movement feel authentically LEGO rather than just "a tiny human".
Control RigBuilt into UE5
Epic Docs → Control Rig
RETARGETING WORKFLOW — Human Mocap → LEGO Skeleton
// PHASE 1: Build the LEGO IK Rig (do once)
1. Import LEGO character FBX with custom skeleton into UE
2. Right-click LEGO Skeleton → Create IK Rig
3. Define bone chains: Spine, Left/Right arms, Left/Right legs
4. Set LEGO-specific joint limits (no wrist rotation, limited elbow bend)
5. Add Full Body IK goal for foot grounding

// PHASE 2: Build IK Rig for the mocap source skeleton
6. Create IK Rig for the source skeleton from the suit
7. Define the same chain structure (UE preset naming works well)

// PHASE 3: Create the IK Retargeter
8. Right-click in Content Browser → Create IK Retargeter
9. Assign Source IK Rig (human) and Target IK Rig (LEGO)
10. Enable Spatially Aware Retargeting (UE 5.7) for proportion handling
11. Adjust Target Actor Scale; test in Preview window

// PHASE 4: Live retargeting via Animation Blueprint
12. In LEGO character AnimBP: receive Live Link body data
13. Pass through Retarget Component → IK Retargeter
14. Layer Control Rig for stylization (squash, timing, constraints)
15. Output Pose → character moves in real time
✅
UE 5.7 advantage: Spatially Aware Retargeting reduces self-collision and artifacts when retargeting between characters of very different scale and proportions. Target UE 5.7 from day one.

Broadcast Output — NDI, Alpha Feeds & Live Switching

Getting Unreal's output onto air and into downstream broadcast systems

📺
NDI Unreal Engine SDK
NDI (Vizrt) · Free SDK
Adds full IP video/audio support within Unreal Engine 5.6+. Enables UE to send and receive video streams over IP — including alpha channel — up to 4K. Add NDI Broadcast Actors to the level (one per camera) and stream each to separate NDI channels simultaneously.
Free SDKNDI ProtocolUE 5.6+
ndi.video/for-developers/ndi-unreal-engine-sdk
🎬
Unreal Motion Design
Built into UE5 · Free
UE5's broadcast-style graphics tools — lower thirds, stingers, and overlays built directly inside Unreal. No external graphics system needed for the POC. Operators can trigger and control via OSC or Blueprint from a production desk.
Motion DesignBuilt into UE5
Epic Docs → Motion Design
🔀
vMix / OBS (Production Switcher)
3rd Party · vMix from $60 one-time
Receives NDI streams from Unreal (LEGO characters, sports footage, graphics). Acts as the production switcher — handling camera cuts, transitions, scene presets, and final programme output. vMix is the industry standard for this workflow.
NDI compatiblevMix licence
vmix.com
NDI OUTPUT SETUP — Unreal Engine to vMix/Switcher
1. Download NDI Unreal Engine SDK from ndi.video/for-developers
2. Place plugin in your UE project's Plugins/ folder
3. Enable "NDI IO Plugin" in UE Plugins panel — restart UE

// Set up multiple NDI output streams (one per virtual camera)
4. In Level, Place Actors → search "NDI Broadcast Actor"
5. Drop one per camera angle (Wide, Medium, Close-up)
6. For each: create NDI Media Sender asset with stream name + resolution
7. Enable "Begin Broadcast On Play" in Project Settings → NDI

// In vMix
8.  Add Input → NDI → search for "UE_Wide" etc. on the network
9.  Add second input for live sports footage
10. Composite LEGO characters over sports using vMix Alpha channel
11. Set up scene presets: Wide 2-shot, Medium single, Close-up, Replay
12. Output to streaming encoder, record, and social clip simultaneously

AR Layer — Real-Time Compositing & Broadcast AR

Overlaying LEGO characters and graphics onto live sports footage

Approach A (Composure in UE) is the fastest and cheapest POC path. Approach B (Zero Density Reality) is the broadcast-grade production path for full deployment.

🎭
Composure (Built into UE5)
Approach A — POC path · Free
Unreal's built-in real-time compositing framework. Receives live video input (via NDI or capture card), composites the LEGO characters and CG elements over it, and outputs a final mixed frame — all inside UE without external software. Sufficient for the 2-minute POC.
Composure PluginBuilt into UE5
Epic Docs → Composure Overview
📡
Zero Density Reality 5 (+ Lino)
Approach B — Full broadcast · Licensed
Industry standard for broadcast AR/XR (FIFA World Cup, Super Bowl, Olympics). UE5-native platform with professional keying, node-based compositing, camera tracking, and real-time data. Reality 5.6 added Lino — a unified template-based workflow for 2D/3D overlays, AR, XR from a single control interface.
LicensedUE5 nativeBroadcast grade
zerodensity.io → Reality platform
📷
Ncam AR Suite (UE Plugin)
Approach B alt · Licensed
Automated UE5 AR pipeline bridge connecting real-time camera tracking to Unreal for film, TV and broadcast AR. Updated for UE5 with SDKLite protocol, wireless operation, and Epic's built-in lens distortion framework. Used on Amazon and Warner Bros productions.
LicensedUE5 plugin
ncam-tech.com
POC AR SETUP — Composure Approach (Inside UE5)
1. Edit → Plugins → "Composure" → Enable → Restart UE

// Bring in live sports footage as video input
2. Option A — NDI Receive Actor → point to sports footage NDI source
3. Option B — Media Framework with video file (for POC testing)

// Build the compositing tree
4. Window → Composure → Create Comp Shot → add layers:
     Layer 1: Background plate (sports footage)
     Layer 2: CG characters (LEGO announcers)
     Layer 3: Graphics overlays (score bugs, lower thirds)
5. Set up alpha keying / matte output for each CG layer

// Output the composite
6. Route Composure output to NDI Broadcast Actor
7. This "final composite" stream goes to vMix programme output

Key Watch-outs & Technical Flags

Issues identified through research that need active management

🔴
iOS 26 / Live Link Face crash: Multiple App Store reviews (May 2026) confirm the Live Link Face app crashes after 10–15 minutes on iOS 26. Don't upgrade performer iPhones — stay on iOS 18 — or switch to Android devices for face capture until Epic release a patch. Flag this to the talent team now.
⚠️
LEGO face blendshapes are a custom art task: Unlike MetaHumans (which have 52 ARKit blendshapes pre-built), LEGO characters need ARKit morph targets authored from scratch. This is an art/rigging task — roughly 5–10 days for an experienced facial rigger. Scope into Week 3–4.
⚠️
UDP Messaging must be enabled before packaging: If you package the UE project for a broadcast build on a dedicated render machine, the UDP Messaging plugin must be enabled with the network binding set to your specific IP — not 0.0.0.0 on Windows (which only binds to default interface).
💡
Rokoko vs Xsens — choose one for POC: Rokoko is cheaper and faster to set up; Xsens is more precise and field-proven at major broadcast events. For the POC, Rokoko is the pragmatic choice. For Phase 5 live events, Xsens or a hybrid workflow is worth evaluating. Both use the same Live Link architecture so swapping is possible.
💡
UE 5.7 is the target engine version: Spatially Aware Retargeting, improved IK Retargeter, multi-NDI broadcast tutorials, updated Live Link Face support (including Android and USB-C cameras) all landed in 5.7. Build on 5.7 from day one.
✅
Use Live Link Hub for multi-performer sync: With two performers (two suits + two iPhones), Live Link Hub handles synchronising and recording all four streams simultaneously with timecode alignment. Set this up early — syncing manually in AnimBP is error-prone under live conditions.
✅
Zero Density early conversation: ZD's Reality platform was demonstrated at NAB 2025 turning a compact LED stage into a full virtual sports studio with web-controlled AR. An early conversation about the LEGO project — even just a demo — is worthwhile for Phase 3 scoping. They have an Open Studio License Program from IBC 2024.
