02 — Technology Stack

PLATFORMS & SOFTWARE

🦾
Rokoko Smartsuit
Body Mocap
Full-body inertial suit captures every movement from the performers in real time. Connects wirelessly and streams live data.
📡
Xsens
Precision Body Capture
Backup / alternative inertial capture system for high-accuracy full-body tracking. Used alongside or instead of Rokoko.
😶
Face Capture
Facial Performance
Captures facial expressions and lip sync in real time via iPhone or Android. Drives the LEGO face for expressiveness.
🎮
Unreal Engine 5
Core Real-Time Engine
The heart of the system. Receives mocap data, renders the LEGO characters and virtual studio environment in real time.
🔗
Live Link (UE Plugin)
Mocap→Engine Bridge
Unreal Engine's built-in plugin that receives live data from mocap suits and face capture, applying it to LEGO rigs in real time.
🧱
Custom LEGO Rig
Character Retargeting
A bespoke skeleton rig that translates human proportions into LEGO minifigure proportions — preserving intent while adding LEGO charm.
🖥️
Broadcast Engine / vMix
Live Switching & Output
Production switcher handling multi-camera feeds, scene transitions, overlays, keying, and final output routing.
🎞️
NDI / SDI
Signal Transport
Industry protocols for moving video signals between systems with minimal latency. NDI over IP; SDI for broadcast cabling.
☁️
Cloud / Remote Stack
Remote Collaboration
Enables remote participation — performers and directors in different locations. Can be run fully remotely for POC.

03 — Implementation

HOW IT'S BUILT

🎭 Capture Setup
  • Two performers fitted with Rokoko/Xsens inertial suits
  • iPhone or webcam face capture mounted on each performer
  • Suits stream wirelessly to capture workstation
  • Live Link streams body + face data into Unreal Engine
  • Both announcers captured simultaneously
🧱 LEGO Character System
  • Human skeleton data mapped to LEGO skeleton via custom solver
  • LEGO joint constraints respected (limited rotation ranges)
  • Stylization layer adds LEGO charm, squash & stretch
  • Facial expressions retargeted to LEGO head rig
  • Two distinct announcer character designs
🎮 Unreal Engine Environment
  • Virtual sports broadcast desk and studio built in Unreal
  • Photoreal stadium background composited with live sports footage
  • Dynamic lighting and real-time reflections
  • Multiple virtual camera presets (wide, medium, close-up)
  • Alpha/keyer output for clean compositing
📡 Live Production & Output
  • Broadcast switcher with scene presets and transitions
  • Live graphics overlays (scores, stats, lower thirds)
  • Multi-camera switching with director control
  • Clean alpha feed output for downstream graphics
  • Delivered as live stream, broadcast file, and social clips

05 — Production Timeline

POC BUILD TIMELINE

Week 1–2
R&D & Pipeline Design
Research, technology selection, and pipeline architecture. Confirm mocap hardware (Rokoko vs Xsens). Test Live Link connection into Unreal. Define LEGO rig requirements. Set up project infrastructure.
Preparation
Week 3–4
LEGO Character & Rig Build
Build the custom LEGO skeleton rig. Create the retargeting solver (human→LEGO proportions). Develop the stylization layer for charm and expressiveness. Build both announcer character designs in Unreal.
Build
Week 5–6
Unreal Environment & Broadcast Setup
Build the virtual sports broadcast studio in Unreal Engine. Integrate live sports footage compositing. Set up virtual cameras, lighting, and alpha keying. Configure broadcast switcher, scene presets, graphics overlays, and live data feeds.
Build
Week 7
Integration & Full Pipeline Test
End-to-end pipeline testing with both performers. Verify low latency from capture to output. Test multi-camera switching workflow. Identify and fix any bottlenecks. Stress test broadcast output and signal routing.
Integration
Week 8
Rehearsal & POC Production Day
Full rehearsal with talent. Creative direction and performance notes. Run the 2-minute POC live. Record multiple takes. Capture broadcast output, social clips, and isolated alpha feeds.
POC Day
Week 9
Post, QA & Delivery
Polish and QA the POC output. Colour grade and audio mix final version. Prepare broadcast-ready deliverables. Create social format cuts. Compile technical documentation for next phase. Present to LEGO/Tongal for review.
Delivery
